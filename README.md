# مصروفي | Masrofy

مشروع Android أولي لتطبيق مصروفات شخصي عربي (RTL) باستخدام Kotlin وJetpack Compose.

> هذه نسخة هيكلية أولية: واجهة تسجيل مصروفات تجريبية، وليست بعدُ إصدارًا جاهزًا للاستخدام المالي. التخزين الحالي مؤقت أثناء تشغيل الشاشة؛ يجب إضافة Room والميزانيات والتنبيهات والتحليلات قبل الاعتماد عليه.

## البناء
يمكن بناء APK عبر GitHub Actions بعد رفع الملفات إلى المستودع. من تبويب Actions شغّل workflow باسم Build Masrofy APK، ثم نزّل artifact باسم Masrofy-APK.
