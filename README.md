مصروفي | Masrofy

تطبيق عربي لإدارة المصروفات الشخصية على Android.

المميزات

- واجهة عربية بالكامل مع دعم RTL.
- العملة: الجنيه المصري.
- تسجيل المصروفات وتصنيفها.
- متابعة الميزانية الشهرية.
- تحليل المصروفات والإنفاق اليومي.
- تخزين البيانات محليًا على الهاتف.
- لا يحتاج إلى حساب أو إنترنت للاستخدام اليومي.
